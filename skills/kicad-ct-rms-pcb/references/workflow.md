# 5 V CT RMS 转直流测量板：已验证的流程与经验

## 1. 本流程解决什么问题

目标是把电流互感器（CT）或等效低电平交流传感器的二次侧电压，转成
可由 ADC 读取的直流电压。参考指标为：

| 项目 | 参考值 |
|---|---:|
| 供电 | 5 V DC |
| 输入 | 0–300 mVrms、50 Hz |
| 输出 | 约 0–3.0 V DC |
| 标称传输 | 10.0 V/V |
| RMS 器件 | LTC1967（官方宏模型） |
| 输入缓冲 | BC547B NPN 射极跟随器 |
| 输出放大器 | OPA333（单电源、零漂移） |

这是一块**低压测量调理板**，不是可直接接入市电的安全隔离方案。CT、
负载电阻、绝缘等级、连接器与机械结构须按最终系统的安全要求独立设计。

## 2. 已收敛的电路参数

### 输入、偏置和 RMS 部分

| 位号 | 数值/型号 | 作用 |
|---|---|---|
| Q1 | BC547B，TO-92 | 高输入阻抗射极跟随缓冲 |
| R1、R2、R4 | 47 kΩ，1% | 输入/偏置网络 |
| R3 | 10 kΩ，1% | 射极/缓冲网络 |
| R5 | 22 kΩ，1% | VBIAS 微调的固定上臂 |
| RV1 | 10 kΩ，Bourns 3296W | VBIAS 微调；作变阻器，滑动端与低端接地 |
| C1 | 1 µF | 输入耦合 |
| C2 | 10 µF | 偏置去耦 |
| U1 | LTC1967CMS8，MSOP-8 | 真 RMS 到 DC |
| C6 | 10 µF | LTC1967 输出平均，50 Hz 时务必留足稳定时间 |
| C5 | 100 nF | 5 V 就地去耦 |

### 输出增益和滤波部分

| 位号 | 数值/型号 | 作用 |
|---|---|---|
| U2 | OPA333AIDR，SOT-23-5 | 单电源非反相放大 |
| R6 | 10.0 kΩ，0.1% | 非反相增益下臂 |
| R7 | 93.1 kΩ，0.1% | 增益微调的固定上臂 |
| RV2 | 5 kΩ，Bourns 3296W | 增益微调；滑动端与低端接 VGAIN |
| R8 | 1 kΩ | 输出隔离/滤波 |
| C4 | 10 µF | 输出低通滤波 |
| ADC 负载 | 100 kΩ（仿真） | 最终应按 ADC 输入网络复核 |

R7 + RV2 对应的放大器名义增益为 `1 + Rfb / R6`。在这组模型、
输出串联/负载条件下，RV2 调到约 **0.44 kΩ** 可把 300 mVrms 标定到
约 3.000 V；实际成板必须在已知输入处校准。

## 3. 仿真做法与结果

### 模型和激励

1. 使用 LTC1967 官方宏模型，而不是理想 RMS 方块；记录模型来源和版本。
2. 5 V 单电源下，把输入交流叠加在约 1.85 V 的共模/偏置上，满足宏模型
   的输入工作条件。
3. 用正弦源，频率 50 Hz；将输入由 Vrms 换算为峰值：`Vpk = Vrms × √2`。
4. 每次瞬态仿真要越过 C6 引起的启动过程；只在稳定尾段求输出平均值。
5. 扫描 0、50、100、150、200、250、300 mVrms，并保存 netlist 与结果表。

### 本次基准仿真结果

下表为优化后模型的稳定尾段平均值，使用约 10.26 V/V 的最终标定增益。

| 输入（Vrms） | RMS 原始均值（V） | 最终输出（V） |
|---:|---:|---:|
| 0.000 | 0.001905 | 0.01935 |
| 0.050 | 0.048777 | 0.49549 |
| 0.100 | 0.097543 | 0.99086 |
| 0.150 | 0.146321 | 1.48637 |
| 0.200 | 0.195103 | 1.98191 |
| 0.250 | 0.243891 | 2.47751 |
| 0.300 | 0.292658 | 2.97290 |

结论：曲线在量程内近似线性，300 mVrms 可调到 3.000 V。零输入约有
19.5 mV 输出残余，应在 ADC 固件中扣除零点，或在生产校准中保存零点与
满量程两点系数。不要为追求“绝对零”把输入偏置或 RMS 模型换成不真实的
理想元件。

### 必须在成板后重新校准的因素

- CT 型号、匝比、相位误差、额定电流和饱和点；
- 二次侧负载/负担电阻及线缆阻抗；
- LTC1967、OPA333、R6/R7 和三极管的批次与温度；
- ADC 输入阻抗、采样电容、保护网络和参考电压。

建议校准顺序：断开输入记录零点，输入一个可溯源的 300 mVrms/50 Hz 标准
信号调 RV2 至 3.000 V，再在 50%、100% 点验证；最后把零点、斜率写入固件。

## 4. KiCad 10 原理图的正确性门槛

### 先选择真实符号、再画网络

- LTC1967 选真实 8 引脚封装/符号；OPA333 使用真实单运放符号并正确处理
  电源单元。禁止用虚拟放大器留给 PCB 阶段再替换。
- RV1 和 RV2 是三端可调电阻。原理图中必须呈现两个电阻端和 wiper，且按上表
  的“变阻器”接法短接滑动端到指定端，才能和实际 3296W 一致。
- 为 `CT_AC`、`BUF_BASE`、`BUF_AC`、`VBIAS`、`VBIAS_TRIM`、`RMS_RAW`、
  `FBN`、`VGAIN`、`VGAIN_TRIM`、`VOUT_0_3V`、`VCC_5V`、`GND` 建立明确标签。

### 视觉连上不等于电气连上

曾遇到器件/标签看起来接触、但因不在 KiCad 网格点上而未连通的情况。正确
做法是：

1. 生成 netlist，逐项核对每个关键网络的器件引脚；
2. 对遗漏引脚，删除原有标签或线段，在符号引脚的准确栅格点重新放置；
3. 再次生成 netlist，最后运行 ERC；
4. 仅在 ERC **0 errors** 后进入 PCB。

本次最终检查中特别验证：R3/1 在 `BUF_AC`，R1/2 和 R2/1 在
`BUF_BASE`。此类漏连会让画面“正确”、仿真/PCB 却完全错误。

## 5. 封装选择与 PCB 启动

下表是这次项目的成熟封装组合；可按制造能力改成 0603/1206，但改动后需重做
丝印、间距、DRC 和热设计检查。

| 类别 | KiCad footprint |
|---|---|
| 普通电阻 | `Resistor_SMD:R_0805_2012Metric` |
| C1、C5 | `Capacitor_SMD:C_0805_2012Metric` |
| C2、C4、C6 | `Capacitor_SMD:C_1206_3216Metric` |
| Q1 | `Package_TO_SOT_THT:TO-92_Inline` |
| U1 | `Package_SO:MSOP-8_3x3mm_P0.65mm` |
| U2 | `Package_TO_SOT_SMD:SOT-23-5` |
| J1/J2/J3 | `TerminalBlock_Phoenix:TerminalBlock_Phoenix_MKDS-1,5-2_1x02_P5.00mm_Horizontal` |
| RV1/RV2 | `Potentiometer_THT:Potentiometer_Bourns_3296W_Vertical` |

流程是：完成封装分配 → 从原理图创建 PCB（不要从一个空白旧 `.kicad_pcb`
继续）→ 设置规则/外形 → 放置 → 查 courtyard → 布线 → DRC。

参考板尺寸为 70 × 45 mm、圆角 3 mm，四个安装孔约在
(104,104)、(166,104)、(104,141)、(166,141) mm。实际尺寸应随外壳、端子出线
和安装孔要求调整。

## 6. 放置、布线与 FreeRouting 的经验

### 手工布局原则

- J1（CT 输入）、J2（5 V 供电）、J3（DC 输出）分开布置，避免输入与输出并行；
- 让 Q1、U1、偏置网络紧凑，RMS 原始节点保持短小、远离输出；
- C5 贴近 U1/U2 供电脚，C6 贴近 U1 输出/平均节点；
- 每移动一次端子或电位器后检查 courtyard overlap 和边缘距离；
- 路径不应只图最短，尤其不要让模拟反馈线跨过电源或输出线。

### 可复现的设计规则起点

- 两层板时，普通净距 0.20 mm，默认线宽 0.25 mm；
- 最小线宽/间距依 PCB 厂能力设置，本次以 0.15 mm 作为较小规则基准；
- 典型通孔 0.60/0.30 mm（焊盘/钻孔参数须随板厂调整）。

### 使用 KiCad MCP 和 FreeRouting 的步骤

1. 先清除所有历史 trace/via。失败尝试留下的短线会让 autorouter 生成短路或
   跨越。
2. **在自动布线前移除铜皮区**。本次 MCP 与某些 FreeRouting 导入组合会忽略
   zone 边界，产生大量错误。先无 zone 路由，确认通网和 DRC，再视工具能力添加
   GND 铜皮并重新 DRC。
3. 当前 KiCad MCP 的自动布线封装曾无法调用新 FreeRouting 2.2.4 JAR；对小板
   验证过的 1.9.0 JAR 可生成并导入 SES。升级 JAR 后先做小型试路由，确认有 SES
   文件和轨迹导入，才可用于正式板。
4. 目标网络应一次列全：
   `CT_AC`、`BUF_BASE`、`BUF_AC`、`VBIAS`、`VBIAS_TRIM`、`RMS_RAW`、
   `FBN`、`VGAIN`、`VGAIN_TRIM`、`VOUT_0_3V`、`VCC_5V`、`GND`。
5. 导入后检查每个目标 net 都有 track；若任何一个缺失，不能称为布线完成。

对本项目，最终无铜皮的自动布线得到 126 条轨迹、2 个过孔，12 个目标网络均已
连接。这个数字是验收线索，不是其他板必须复现的指标。

### SWIG/MCP 与 GUI 的同步问题

KiCad 编辑器和基于文件/SWIG 的 MCP 后端可能争用同一 `.kicad_pcb`。外部脚本
修改板文件（例如为了删除 zones）后，必须立即在 MCP 中 `open_board` 重开，然后
再继续操作；否则 KiCad 的时间戳保护可能拒绝保存或覆盖更改。不要一边在 GUI 中
拖动元件、一边让 SWIG MCP 写同一块板。

## 8. 环境、版本和移植

本流程曾以 KiCad 10.0.5、KiCad API 启用、KiCad MCP（mixelpixx 服务器）、
KiCad 自带 Python 以及 LTspice 26.0.2.1 的 LTC1967 宏模型完成。版本变动可能
影响符号库、MCP 后端和 FreeRouting 调用，因此迁移时先做“打开项目、生成 netlist、
小范围布线、DRC”四项冒烟测试。

将整个 `kicad-ct-rms-pcb` 目录复制到另一台电脑的
`%USERPROFILE%\.codex\skills\`，按该机器的 KiCad/MCP/仿真器安装说明配置，
然后重启 Codex，即可发现并调用本 skill。迁移并不自动安装 KiCad、ngspice、
LTspice、FreeRouting JAR 或 MCP；这些依赖要按本机路径重新设置。
